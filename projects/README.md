# Projects

One file per project (a shoot, a client job, an episode — whatever unit your
work comes in). Rename this folder to match your own vocabulary if you like.

This is where the messy, one-off facts go: what was in this particular batch
of footage, what got picked, what's still pending, what you decided and why.
Reusable facts belong in `knowledge/` instead — if you notice the same note
showing up in project after project, that's a sign it should move there.

## Template

```markdown
# <project name>

- Status: <triage / editing / review / delivered>
- Started: YYYY-MM-DD

## Notes
Whatever's specific to this one: what's in the footage, what was excluded
and why, decisions made, what's still open.
```
